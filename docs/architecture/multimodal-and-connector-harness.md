# Multimodal and Connector Harness

Every advanced capability enters behind the AI SDK UIMessage runtime.

Planned adapters include vision/file input, image generation with reference/style provenance, Microsoft 365/Outlook, Otter.ai, Notion, GitHub, Supabase, knowledge graph promotion, and bounded computer-use sessions.

No mutating adapter is implemented in this PR. Before adding one, require authenticated user ownership, native AI SDK execution approval, typed tool states, sanitized audit output, and explicit persistence rules.

Image generation should model prompt artifact, references, style/profile metadata, generation job, outputs, background-removal/variant handling, and promotion state. Computer use must be bounded and never run as invisible background automation.
